# Lux Omni Blog — Main Navigation Header

## Status
Proposed plan recorded for review. Layout and implementation details are not yet finalized.

## Purpose
The main navigation header is the primary navigation area for Lux Omni Blog. It is separate from the top information bar.

## Components

| Element | Details |
|---|---|
| Lux Omni Logo | Displays the Lux Omni logo and links to the homepage. |
| Tech | Navigation link for technology content. |
| Reviews | Navigation link for product reviews. |
| How To | Navigation link for tutorials and guides. |
| Hardware | Navigation link for hardware-related articles. |
| Software | Navigation link for software-related articles. |
| Buying Advice | Navigation link for buying guides and recommendations. |
| Search button | Opens the website's search interface. |
| Dark-mode toggle | Lets visitors switch between light and dark themes. |

## Not Yet Decided

- Responsive/mobile behavior
- Search implementation
- Whether the selected theme persists between visits
- Exact destination URLs for navigation links
